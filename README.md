# 🎯 Sharp Shooter — Multiplayer Game

Многопользовательская игра «Меткий стрелок», разработанная в рамках учебного курса «Разработка сетевых приложений на Java».

Проект развивался поэтапно через четыре лабораторные работы — от простой одиночной игры до полноценного клиент-серверного приложения с базой данных и Android-клиентом.

## 🚀 Лабораторные работы

### Л.р. 1 — Игра (JavaFX)
Одиночная игра с двумя движущимися мишенями. Игрок стреляет стрелой слева направо.

- Ближняя мишень — **1 очко**, дальняя — **2 очка**
- Победа при наборе **6 очков**
- Пауза через `wait/notify` — поток засыпает, не тратя ресурсы процессора
- Разделение логики и отрисовки через `AtomicReference<GameState>`

### Л.р. 2 — Клиент-серверное взаимодействие (Socket, ServerSocket)
Многопользовательский режим до **4 игроков** по сети.

- Сервер контролирует всю игровую логику — мишени, стрелы, попадания
- Клиент только отображает состояние, полученное от сервера
- Общение через JSON (`Gson`) по TCP сокету
- Пауза через `wait/notify` на сервере — тот же паттерн что в л.р. 1
- Синхронизация через `synchronized` блоки и `volatile` флаги
- Каждый клиент обслуживается отдельным потоком (`ClientHandler`)

**Протокол сообщений:**

| Направление | Тип | Описание |
|---|---|---|
| Клиент → Сервер | `JOIN` | Подключиться с именем |
| Клиент → Сервер | `READY` | Готов играть / снять паузу |
| Клиент → Сервер | `SHOOT` | Выстрел |
| Клиент → Сервер | `PAUSE` | Пауза |
| Сервер → Клиент | `JOIN_OK` | Подключение принято |
| Сервер → Клиент | `JOIN_FAIL` | Отказ (имя занято / сервер полон) |
| Сервер → Клиент | `GAME_STATE` | Состояние игры (~100 раз/сек) |
| Сервер → Клиент | `GAME_OVER` | Победитель |

### Л.р. 3 — База данных (Hibernate + SQLite)
Хранение статистики игроков между сессиями.

- **Hibernate 7** + **SQLite** — файловая база данных `sharpshooter.db`
- Таблица `players` — имя игрока и число побед
- Таблица лидеров запрашивается через то же соединение с сервером
- Паттерн **DAO** — вся работа с БД изолирована в `PlayerDao`

**Дополнительные сообщения:**

| Направление | Тип | Описание |
|---|---|---|
| Клиент → Сервер | `LEADERBOARD_REQUEST` | Запрос таблицы лидеров |
| Сервер → Клиент | `LEADERBOARD_RESPONSE` | Таблица лидеров |

### Л.р. 4 — Android-клиент (наблюдатель)
Мобильный клиент на Java для платформы Android.

- Только наблюдение — управление игрой остаётся за Windows-клиентами
- Тот же протокол JSON что и для Windows-клиентов
- Сетевое взаимодействие через `Socket` в отдельном потоке
- Вместо `Platform.runLater()` — `Handler(Looper.getMainLooper()).post()`
- Две активности: главная (список игроков) и таблица лидеров
- Передача данных между активностями через `Intent`

## ▶️ Запуск

### Сервер
```
Запустить ServerLauncher.java в IntelliJ IDEA
Сервер запустится на порту 12345
```

### Windows клиент
```
Запустить HelloApplication.java в IntelliJ IDEA
Ввести имя игрока и подключиться
```

### Android клиент
```
Установить APK на устройство
Убедиться что телефон и компьютер в одной WiFi сети
Ввести IP адрес компьютера и имя наблюдателя
```

> Узнать IP адрес компьютера: `ipconfig` (Windows) → строка IPv4-адрес

## 🎮 Правила игры

- На поле две мишени движутся сверху вниз
- **Ближняя мишень** (большая, медленная) — **1 очко**
- **Дальняя мишень** (маленькая, быстрая) — **2 очка**
- Одновременно в воздухе только одна стрела на игрока
- Победитель — первый набравший **6 очков**
- При паузе игра возобновляется только когда **все** игроки нажмут "Готов"
